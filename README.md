# Meshive (MeshMachine) — product site

The public landing page for **Meshive**, also known as MeshMachine: a local-first control plane that turns a mixed pile of computers — new Macs, old laptops, a Dell, a Chromebox — into one compute fleet.

Live at **https://meshmachine.whitegwireless.com**

## What Meshive does
Machines on your network discover each other and join the fleet, get benchmarked, and receive work matched to what each one is measurably good at. Everything reports back to one control plane, so old hardware keeps doing useful work instead of sitting in a drawer.

## This repo
A single static page (`index.html`, `og-image.png`, `robots.txt`, `sitemap.xml`), served by GitHub Pages on a custom domain. No build step.

The application code is private. Signed release builds are in [meshmachine-releases](https://github.com/humbertowgw-maker/meshmachine-releases). The full story is on the [author's GitHub profile](https://github.com/humbertowgw-maker).
